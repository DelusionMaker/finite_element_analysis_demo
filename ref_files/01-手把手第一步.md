# 有限元，从「完全不懂」到「算出第一根梁」

> 这份是给**有前端/3D 背景、但没系统学过结构力学**的人写的。
> 上一份「开发路线图」偏工具书，这份偏"手把手"。两份配合使用：先看这份建立直觉，再看那份做工程规划。

---

## 〇、先建立一句话直觉

有限元做的事，用初中物理就能说清：

> 一根弹簧用力拉：`F = k · x`（力 = 刚度 × 伸长量）
> 一根桥梁呢？把它**切成一千根小弹簧拼起来**，于是变成 `F = K · u` —— 只不过 `k` 从一个数字变成一张几千行的大表格，`x` 从一个伸长量变成几千个未知数。
> 然后交给计算机解这个方程组。

**难点从来不是解方程组**（高斯消元 30 行代码就写完），而是**那张表格 K 怎么填**。剩下的所有术语，都只是围绕"怎么填、怎么校验"。

---

## 一、四个词，用人话解释

| 术语 | 人话 | 类比 |
|---|---|---|
| **节点 Node** | 你打算把梁切成几段，切点上钉一个"观察点" | 尺子上的刻度 |
| **单元 Element** | 两个相邻节点之间的那一段 | 一根小弹簧 |
| **自由度 DOF** | 一个节点能往几个方向动。平面里是 2 个（上下 + 转动），空间里是 6 个（三个平移 + 三个转动） | 游戏里一个物体的坐标通道数 |
| **刚度矩阵 K** | 一张表，回答"让第 j 号自由度动 1 个单位，需要在第 i 号自由度上施加多大的力" | 一根弹簧的 `k`，但是升级成表格版 |

再加两个容易混的：

- **E（弹性模量）**：材料本身有多硬。钢材 2.1×10¹¹ Pa，混凝土 3×10¹⁰ Pa。**这是材料属性，和形状无关。**
- **I（截面惯性矩）**：截面形状有多抗弯。同样多的钢材，做成工字型比做成方形抗弯得多。**这是几何属性，和材料无关。**

抗弯能力 = `E × I`。这就是你看到满屏 `EI` 的原因。

## 二、跟着做：六个动作

### 动作 1：把梁切开（1 分钟）

一根 6 m 的梁，跨中要受力，那就**必须在跨中放一个节点**，否则力加不上去。

```
节点0 ────── 节点1 ────── 节点2
x=0         x=3m        x=6m
  └── 单元0 ──┘└── 单元1 ──┘
```

每个节点有 2 个未知数（竖向位移 v、转角 θ），3 个节点 = **6 个未知数**。
把它们排成一列，编号定死：

```
[v0, θ0, v1, θ1, v2, θ2] → 编号 [0, 1, 2, 3, 4, 5]
```

> 💡 这一步在代码里就是一个 `2 * nodeId` 和 `2 * nodeId + 1` 的映射函数。**编号规则先定死，后面全靠它。**

---

### 动作 2：给每一小段算一张 4×4 的表

这一段要回答："让它的两端动起来，需要多大力？"

答案在结构力学课本上是现成的，不用你推导，直接抄：

```
           ⎡  12     6L    −12     6L  ⎤
k = EI/L³ ·⎢  6L    4L²    −6L    2L² ⎥
           ⎢ −12    −6L     12    −6L  ⎥
           ⎣  6L    2L²    −6L    4L²  ⎦

列的顺序：[v_i, θ_i, v_j, θ_j]
```

怎么读这张表？举 `k[0][1] = 6EI/L²` 的意思：**想让 i 端转角 θ_i 变化 1 弧度，需要在 i 端竖向施加 6EI/L² 的力。**

> ⚠️ **第一件事永远是检查这张表是否对称**（`k[0][1]` 应该 = `k[1][0]`）。这条检查能在你还没算任何结构之前，抓出 90% 的手抄错误。

---

### 动作 3：把两张小表叠成一张大表（组装）

两个单元在**中间节点 1 相遇**，所以它们的贡献要相加。

代码只有这 5 行：

```js
for (const el of elements) {
  const map = [2*el.n[0], 2*el.n[0]+1, 2*el.n[1], 2*el.n[1]+1];  // 这个单元用到哪 4 个编号
  for (let r = 0; r < 4; r++)
    for (let c = 0; c < 4; c++)
      K[map[r]][map[c]] += ke[r][c];   // ← 注意是 +=，不是 =
}
```

那个 `+=` 是整个组装的全部秘密：**共用节点位置上的数字相加。**

跑出来的 6×6 长这样（取自实际输出）：

```
                  v0          θ0          v1          θ1          v2          θ2
     v0     7.467e+6    1.120e+7   -7.467e+6    1.120e+7           0           0
     θ0     1.120e+7    2.240e+7   -1.120e+7    1.120e+7           0           0
     v1    -7.467e+6   -1.120e+7    1.493e+7           0   -7.467e+6    1.120e+7
     θ1     1.120e+7    1.120e+7           0    4.480e+7   -1.120e+7    1.120e+7
     v2            0           0   -7.467e+6   -1.120e+7    7.467e+6   -1.120e+7
     θ2            0           0    1.120e+7    1.120e+7   -1.120e+7    2.240e+7
```

看 `v1` 那格的 **1.493e+7**，它是两个单元的左上角 `7.467e+6` 相加得来的。
看 `v0/v2` 那两行大部分是 0 —— 因为节点 0 只被单元 0 碰到，跟节点 2 完全没直接关系。**这几行零，就是有限元矩阵"稀疏"的来源**，也是后面优化性能的抓手。

---

### 动作 4：告诉程序哪里是支座（施加约束）

桥的两端搭在桥墩上，竖向不能动，但可以转动。所以 `v0 = 0`、`v2 = 0`。

这里有个**新手一定会遇到的选择**，我直接给你结论：

| 做法 | 怎么弄 | 评价 |
|---|---|---|
| ❌ 罚函数法 | 把对角元改成 `1e30` | 简单，但会让矩阵条件数爆炸，几千自由度以上开始出鬼 |
| ✅ **置 1 置 0 + 右端修正** | 该行该列清零、对角元置 1、右端项设为给定位移 | **保持矩阵对称正定，推荐** |

代码长这样：

```js
function applyBoundary(K, F, constraints) {   // constraints: Map<自由度编号, 位移值>
  for (const [d, value] of constraints) {
    const colSnapshot = K.map(row => row[d]);      // 先存下这一列
    for (let i = 0; i < n; i++) {
      if (i === d) continue;
      F[i] -= colSnapshot[i] * value;              // 已知位移的影响挪到等号右边
      K[i][d] = 0; K[d][i] = 0;
    }
    K[d][d] = 1; F[d] = value;
  }
}
```

> 💡 为什么要挪到右边？因为 `v0 = 0` 时它不影响别人；但如果某支座**沉降了 5 mm**（`v0 = -0.005`），这个已知位移会挤压旁边的单元。这一行 `F[i] -= K[i][d] * value` 就是在处理这件事。桥梁里**支座沉降工况**就靠它。

### 动作 5：解方程

```js
function solveLinearSystem(A, b) { /* 高斯消元，30 行 */ }
```

完整代码在 `learn.js`。**这段和力学完全无关**，是纯数值方法，你可以直接用任何线性代数库替代。

一个必须注意的点：**奇异性判断要用相对阈值。**

```js
let maxAbs = 0;
for (const row of A) for (const v of row) maxAbs = Math.max(maxAbs, Math.abs(v));
const singTol = maxAbs * 1e-12;   // ← 跟着矩阵自身量级走
```

为什么？因为忘了加约束时，理论上该是 0 的主元在浮点运算里会残留成 `-1.55e-9`（这是脚本实际跑出来的值）。如果你写死 `if (pivot < 1e-14)`，它会**顺利通过检查，然后给你一堆 1e20 的位移**。相对阈值才会把它抓住。

### 动作 6：拿解析解验收（这步不能省）

这是**整个项目最重要的一步**。桥梁公式可以不知道，但下面这几个必须会，因为它们是你的"标准答案"：

| 情况 | 公式 | 本例数值 |
|---|---|---|
| 简支梁跨中受力 | 跨中挠度 `δ = −PL³ / (48EI)` | −0.2679 mm |
| 悬臂梁端部受力 | 端挠度 `δ = −PL³ / (3EI)` | — |
| 悬臂梁满布荷载 | 端挠度 `δ = −wL⁴ / (8EI)`，端转角 `θ = −wL³ / (6EI)` | −0.9524 mm / −3.17e-4 rad |

实际运行结果：

```
理论 δ = −PL³/(48EI) = -0.2679 mm
有限元 δ            = -0.2679 mm
相对误差            = 0.00e+0 %  ✅ 通过
```

**误差是 0，不是"很小"，是完全相等。** 这不是巧合：

> 🎯 梁单元的形函数是**三次多项式**，而简支梁在节点集中力下的真实挠度曲线恰好也是分段的三次函数。
> **所以节点位移是精确解** —— 你把网格加密一倍，节点位移一个数字都不会变。
>
> 认识到这一点，你就再也不会陷入"是不是网格不够密"的自我怀疑。**节点位移不准，一定是代码错了，不是网格不够。**

## 三、一个反直觉的知识：分布荷载怎么变成节点力

真实桥梁的力大多不是集中在节点上的，而是**铺满全梁**（自重、铺装、车道荷载）。计算机只认节点，所以要先把它们"翻译"成节点力。

对一根满布均布荷载 `q` 的单元，翻译结果是：

```
f = [ qL/2 ,  qL²/12 ,  qL/2 ,  −qL²/12 ]
      ↑竖向力  ↑端弯矩   ↑竖向力   ↑端弯矩
```

**那个 `−qL²/12` 是最容易抄错的一格** —— 两端弯矩大小相同、转向相反。

> 💡 **建议别手抄固端力表，直接数值积分：**
> `f = ∫ Nᵀ(x)·q dx`，用两点高斯积分即可（对三次多项式精确）。
> 好处：任意梯形分布、任意方向都能统一处理，彻底告别符号错误。

## 四、三个必踩的坑，先认识它们的样子

`learn.js` 的例 3 故意复现了这三个：

### 坑 A：忘了加约束 → 模型飞上天

```
✅ 坑A 成功复现 → ❌ 矩阵在第 4 列接近奇异（主元 -1.55e-9，阈值 4.48e-5）
      最常见的原因：支座约束加少了，结构还能整体平移或转动（称为"机构"）。
```

处理办法：**捕获这个异常，友好地告诉用户"第 N 号节点的哪个方向没约束住"**，而不是让 NaN 一路流到 UI 上变成一个飞出天际的模型。

### 坑 B：手抄公式错 → 结果似是而非

防御手段只有一条，**写死成单元测试**：

```js
expect(maxAbsOffDiagonalDiff(ke, transpose(ke))).toBeLessThan(1e-12);
```

在你还没算任何结构之前就能抓错。

### 坑 C：单位混用 → 桥"完全不变形"

把 `I` 从 m⁴ 当成 mm⁴ 用，刚度放大 **1e12 倍**，位移就小 1e12 倍。

```
✅ 坑C 演示：把 I 从 m⁴ 当成 mm⁴ 用，刚度会放大 1.00e+12 倍
```

防御：README 第一行写死单位制（推荐 **N · m · Pa**），UI 顶部常显，输入框带单位后缀。

## 五、从「2×2」升级到真正的桥梁：只多了三件事

本教程用的是**平面梁单元**（每节点 2 个自由度）。真正的桥梁用**空间梁单元**（每节点 6 个自由度），差别只有：

| 增加的项 | 物理含义 | 对应的表格增量 |
|---|---|---|
| **轴向变形** | 梁能被拉长压短 | 加 `EA/L` 项，作用在 u 方向 |
| **扭转** | 梁能被拧 | 加 `GJ/L` 项，作用在 θx 方向 |
| **另一个方向的弯曲** | 横向也有弯矩 Iz | 再加一组和已有弯曲一样的 4×4 块 |

于是表格从 **4×4 变成 12×12**，但**思路一模一样**：还是"算小表 → 用 `+=` 叠大表 → 加约束 → 解方程"。

此外还要多一个 **坐标变换**：因为空间里的梁朝向各异，需要把每根梁的局部坐标转到全局坐标：

```
Λ = [x̂; ŷ; ẑ]  (3×3 方向余弦矩阵)
T = 四个 Λ 拼成的 12×12 块对角阵
k_global = Tᵀ · k_local · T
```

> ⚠️ **这是"结果差一倍 / 两个方向搞反"的头号来源。** 箱梁的横向和竖向刚度常常差一个量级，局部轴一旦旋转 90°，结果完全错误。
> 防御：给每根梁一个显式的"参考方向"字段，UI 里提供"显示局部坐标轴"开关，并写一条**"把整个模型旋转 45°，位移大小应不变"**的测试。

## 七、通关之后做什么

按顺序来，每一步都能独立验证：

1. **改参数跑真桥** —— 把 L、I、E 换成你项目的真实数字，看看量级对不对（公路桥活载下的挠度应该在 mm~cm 级）
2. **加自动划分循环** —— 别再手写节点，写个 `for` 按间距生成 N 个节点、N-1 个单元
3. **升级到 12×12 空间梁单元** —— 加轴向 + 扭转 + 双向弯曲
4. **加第二个工况，验证比例性** —— 荷载翻倍，位移必须精确翻倍（这条能抓出非线性 bug）
5. **做多跨连续梁** —— 中间墩用竖向约束；这时第一跨受载会让第二跨抬起，需要负反力检查
6. **接 Three.js 画变形和云图** —— 到这里就是你的主场了
