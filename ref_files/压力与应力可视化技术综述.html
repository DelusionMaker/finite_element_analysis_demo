00总览与定位

0.1 为什么压力与应力需要专门研究可视化

在物理仿真管线 —— 几何建模 → 连续方程 → 空间离散 → 时间积分 → 求解线性/非线性系统 —— 中，压力与应力处于一个尴尬的位置：它们是驱动整个动力学演化的核心量，却无法被直接拍摄。位移可以看到、界面可以看到，但"内部某一点的 von Mises 等效应力是 237 MPa"这件事没有任何光学手段能直接验证。于是可视化承担三重角色：

  1. 判读（reading）：把数值场的空间结构变成人眼可解码的图案，回答"哪里高、哪里低、梯度朝哪"。
  2. 验证（verification）：暴露数值伪影 —— 棋盘状压力振荡、沙漏模式、剪切自锁、接触穿透、SPH 压力噪声。绝大多数仿真 bug 是"看"出来的，而不是查出来的。
  3. 沟通（communication）：工程评审、论文配图、影视特效的艺术控制，都要求既科学忠实又视觉可读。

0.2 三条主线：压力 vs 应力 vs 形变

PRESSURE

压力（标量）

各向同性的正应力强度。流体求解的核心未知量，同时是固体应力张量的球量部分。单个数、有符号、无方向。

STRESS

应力（二阶张量）

描述穿过任意取向微面的内力分布。每点 9 个分量（对称后 6 个独立），同时携带强度、方向与各向异性三种信息。

DEFORMATION

形变与拉伸

形变的几何本身是最直白的可视化语言。主拉伸方向与主拉伸率往往比应力张量本身更容易被工程师读懂。

核心难点的一句话总结 压力是标量的、可归一化的，因此相对好画；应力是张量的，一个像素要同时承载 6 个自由度 —— 这是整个领域所有方法论争的根源。没有任何一种张量可视化是"完备"的，只有"针对某个问题的合适近似"。

01数学表示：从标量场到二阶张量场

1.1 场论层级：标量、矢量与张量

物理场按"每个空间点携带多少数值、这些数值在坐标旋转下如何变换"来分类：

  • 0 阶张量（标量场）：p : Ω × [0,T] → R。旋转不变，单点 1 个数。
  • 1 阶张量（矢量场）：u, ∇p, t : Ω → R³。单点 3 个数，正交变换 Q 下满足 u' = Q u。
  • 2 阶张量（张量场）：σ : Ω → R^(3×3)。单点 9 个数，变换规律 σ' = Q σ Qᵀ。这是与矢量场的本质分水岭：矢量只有一个方向，张量有多个彼此耦合的方向。

1.2 压力：标量场的物理含义

在不可压缩 Navier–Stokes 方程中，压力不是状态变量，而是约束反力（本质上是不可压缩约束的 Lagrange 乘子）：

ρ (∂u/∂t + u·∇u) = −∇p + μ∇²u + ρg (动量守恒) ∇·u = 0 (不可压缩约束) ⇒ ∇²p = −ρ (∇u : ∇u) (压力 Poisson 方程，PPE)

由此产生几条直接决定可视化设计的性质：

  • 压力只有相对意义：不可压缩流中 p 可差任意常数。多帧 / 多工况对比前必须统一基准（远场取 0 或扣除域平均），否则整幅图会漂移。
  • 压力梯度才是驱动力：推动流体的是 −∇p 而非 p 本身。用矢量图叠加显示 ∇p 与 u 的关系，是判断投影步是否正确的经典手法。
  • 压力 Poisson 方程是全局的：任何局部误差会以椭圆型方式扩散到全域 —— 可视化上的表现就是"整场发抖"，而不是局部脏点。

可压缩流中 p 通过状态方程闭合（理想气体 p = ρRT、水的 Tait 方程等），此时 p 是真正的热力学变量，绝对值有意义，且常跨好几个数量级 —— 这直接影响色标与归一化选择（见 §2.1）。

1.3 Cauchy 应力张量

面力向量（traction）与 Cauchy 定理是应力可视化的物理起点。给定一个法向为 n 的过流微面，作用于其上的单位面积力记为 t(n)。Cauchy 定理断言 t 对 n 线性依赖：

t(n) = σ · n ，其中 σ = σᵀ (无体力矩 → 角动量守恒 → 对称，6 个独立分量) 法向应力：σ_xx, σ_yy, σ_zz (拉 / 压) 剪 应 力：σ_xy, σ_yz, σ_xz (错切) 平 衡： ∇·σ + ρ b = ρ a

对称性是可视化的重要资产：它保证实特征值 + 正交特征向量，因而应力总能被几何化为三个正交方向上的三个数 —— 这正是所有张量 glyph 的理论地基。

1.4 谱分解：为什么它是可视化的钥匙

对称张量一定可以正交对角化：

σ = Q Λ Qᵀ ， Λ = diag(σ₁, σ₂, σ₃) ， σ₁ ≥ σ₂ ≥ σ₃ 几何含义：任意取向微面上的 traction t(n) = σn；当 n 沿主方向时 t 与 n 平行（纯拉伸/压缩，无剪切） 二次曲面： { x ∈ R³ : xᵀ σ⁻¹ x = 1 } 其半轴长 = √λᵢ ，轴向 = eᵢ

这一步是整个张量可视化的枢纽：它把6 个耦合的数换成3 个数 + 3 个正交方向 —— 恰好构成一个椭球，而椭球是可以被直接画出来的几何对象。所有 glyph 方法都可视为在这个椭球上的变体。

各向异性类型特征值关系几何形态典型物理来源
线性 linearλ₁ ≫ λ₂ ≈ λ₃雪茄状长椭球拉伸主导流动、单向纤维增强材料
平面 planarλ₁ ≈ λ₂ ≫ λ₃薄饼状扁椭球剪切带、面内编织复合材料
各向同性 sphericalλ₁ ≈ λ₂ ≈ λ₃球静水压状态

由 Kindlmann 等人提出的三项式描述可进一步量化成用于着色的标量：

c_l = (λ₁ − λ₂) / (λ₁ + λ₂ + λ₃) 线性度 c_p = 2(λ₂ − λ₃) / (λ₁ + λ₂ + λ₃) 平面度 c_s = 3λ₃ / (λ₁ + λ₂ + λ₃) 球度 三者之和恒为 1 ⇒ 可直接映射到 RGB 构成一个「各向异性色盘」

1.6 构形与应力度量：大变形下的陷阱

有限应变（软体、橡胶、肌肉、大转动结构）下，"应力"必须指明相对哪个构形定义，否则数值差出一整个 J = det F 因子：

度量定义可视化注意点
Cauchy（真应力）σ当前构形单位面积上的力云图应画在变形后的网格上。
1st Piola–Kirchhoff PP = J σ F⁻ᵀ两点张量，参考→当前，不对称，不能直接做谱分解画椭球。
2nd Piola–Kirchhoff SS = J F⁻¹ σ F⁻ᵀ参考构形上对称，有谱分解，但主方向与物理方向不一致。

经典错误 把 Piola–Kirchhoff 应力画在未变形网格上、又把 Cauchy 应力画在放大 10 倍的变形网格上，然后把两幅图放在一起对比。正确做法是渲染构形与应力度量严格匹配 —— 这也是 §2.6"变形网格可视化"要处理的核心问题。

02可视化方法体系

按"信息承载能力"与"空间覆盖方式"两个轴，主要方法可分为六大族。本节逐一拆解其原理、关键参数与适用边界。

2.1 伪彩色映射（Pseudo-color Mapping）

原理

最简单也最被低估的一类：定义映射 C : [d_min, d_max] → RGB，把标量值转为颜色，画在切片、表面或粒子上。看似平凡，但它承担了工程实践中 90% 以上的应力判读工作量，因此细节决定成败。

色标选择的三类语义

SEQUENTIAL

顺序型

用于单调量：von Mises、应变能密度、温度。viridis / inferno / cividis 感知均匀且色盲友好。

DIVERGING

发散型

用于有符号量：压力、σ₃（拉 vs 压）。必须把 0 锚定在中性色，否则人眼会读出错误的高点。

RAINBOW / TURBO

彩虹型（慎用）

业界惯性极大。turbo 修正了 jet 的伪轮廓，但依然存在：非单调亮度会产生假的"脊线"、夸大微小差异、红绿色盲不可读。

值域归一化：比色标更影响结论

策略做法何时用
全局线性整个数据集的 min / max多帧、多工况对比的唯一安全选择
逐帧自适应每帧各用自己的 min / max动画中极易造成"闪烁 + 场在变化的错觉"。除非显式标注，否则不要用
分位裁剪P2 – P98 之外截断并在色标上标出存在少量极端离群值（接触点、裂纹尖端奇异性）
对数 / 符号对数sign(d)·log(1+|d|/ε)跨 3 个以上数量级（爆炸冲击、可压缩流、接触压力）
直方图均衡按累积分布重新映射只用于探索性看图，不可用于给出结论
实践要点 伪彩色只给出 2D 表面 / 切片上的信息，且颜色本身不携带深度。因此它几乎总要配三件套：带数值的色标图例 + 鼠标探针（pick）+ 至少一个正交切面。另外，同一场景多个切片若用不同归一化，会直接导致错误结论。

离散数据的取值位置

  • 节点值（nodal）：连续云图的基础。FEM 内部应力在高斯积分点上最准确，通常需要"应力磨平"（如 superconvergent patch recovery / ZZ 估计）外推到节点。
  • 单元值（cell-centered）：有限体积法、大多数流体求解器的自然输出。画云图前做一次体积加权平均。
  • 粒子值（SPH / PBF / MPM）：无拓扑，需要先插值到背景网格（MLS / SPH kernel sum），或直接做屏幕空间溅射 + 深度合成来规避排序问题。

2.2 等值线与等值面（Isocontour / Isosurface）

原理

给定阈值 c，提取集合 { x : d(x) = c }。2D 用 Marching Squares，3D 用 Marching Cubes（15 种拓扑基例；要正确处理拓扑二义性需用 Marching Cubes 33 或 Asymptotic Decider）。

沿边线性插值定位交点： t = (c − d_A) / (d_B − d_A) ， x = A + t (B − A) 着色法向： n = −∇d / |∇d| ← 要求 d 足够光滑，高斯点应力需先平滑

在压力 / 应力中的典型用法

用法含义注意
压力等值面等压面形状直接反映流动结构（水翼上下表面等压面分离 = 升力来源）不可压缩流需先扣除基准压
von Mises 等值面σ_vm = σ_y 即屈服面的几何可视化，塑性区一目了然建议 2–3 层半透明壳嵌套
多重嵌套等值面半透明多层壳 + peel-off，等价于"洋葱"式体观察需注意透明度排序；配 focus + context
2D 等值线与传统工程制图完全同构，评审无歧义等值线间距可选线性分级或对数分级
裂纹 / 损伤面相场 d ∈ [0,1] 提取 d = 0.9 作为裂纹几何相场带宽 ε 决定阈值敏感度
内在缺陷 等值面本质上是一个二值分类器（在面内 / 不在面内）。它丢掉层间所有信息，外层会遮挡内部结构；对张量更严重 —— 标量等值面完全无法表达各向异性，除非额外引入第二标量做成所谓的 profiled / multilayered surface。

轮廓树与自动阈值

现代工具（TTK、ParaView 的 Persistence Curve）用轮廓树 / 持久性同调自动挑选"有意义的"等值水平：Persistence = d(saddle) − d(extremum)，持久性低的分支被视为噪声。这解决了"手工调阈值调到天荒地老"的实际痛点，也是近年拓扑数据分析（TDA）进入科学可视化的主要落点。

2.3 矢量场方法：∇p、traction 与位移

压力本身是标量，但 −∇p（驱动加速度）、t(n) = σn（任意面面力）与位移场 u 都是矢量。

方法机制适用 / 陷阱
箭头图 / Hedgehog 规则采样点上画线 + 箭头，长度 ∝ |v| 直观、易实现。采样步长与箭长比例必须仔细设定；密度稍大立刻变成"黑色糊状"；对模长跨度大的场要做根号压缩。
流线 / 迹线 / 脉线 沿 dx/ds = v(x) 积分（RK4）。迹线 = 随时间推移的流线；脉线 = 单点注入的染料轨迹 稳态下三者重合。种子点策略（均匀分布 / 曲率自适应 / 兴趣区）决定成败；Tube / Ribbon 化可给出深度线索。
流面 / 流带 / 粒子动画 线性播种生成流面；并行积分生成具有旋转指示的 ribbons 比裸流线更好的深度感知。动画的时间一致性（无抖动、无 pop-in） 是主要难点。
LIC（线积分卷积） 白噪声沿矢量场方向做 1D 卷积，再用第二通道 Texture Transfer Function 上色 给出逐像素密度的方向感，无采样丢失。缺点：只表达方向不表达大小（可用亮度调制）；是最适合密集 / 高频场的方案。
矢量场拓扑 提取临界点（源 / 汇 / 鞍点 / 中心）与分界线，绘制拓扑骨架 把连续场压缩成若干几何不变量，适合多工况对照与自动化特征普查。
标量 – 矢量联合检查的经典组合： u 的流线（Tube 半径 ∝ |u|） + 背景切面上的 p 伪彩 + 稀疏 ∇p 箭头 若投影步正确，则 u 应当散度自由且 ∇p 承担全部加速度：看到 u 流线穿出闭合等值面 = 出错

2.4 张量场线索化：本方向的核心难点

二阶张量场同时拥有强度、方向、各向异性三个属性。学术界把方法分为三类：图元法（glyph / local）、积分法（integral / streamline-like）、特征法（topology / feature）。

② 尺度（scale）：图元大小应与局部特征分辨率匹配；通常以全局 σ₁ 百分位做归一化，再留一个可调系数。
③ 遮挡消解：环境光遮蔽 + 雾效 + 沿视线的 depth-cue；或采用 2.5D —— 只在某个切面 / 表面上布点。

(2) 积分法：超流线与张量线

Delmarcelle & Hesselink（1993）提出的 hyperstreamline 是张量可视化的里程碑：沿最大主方向 e₁ 积分出一条曲线作为脊线，再扫出一个截面为椭圆的管，椭圆两条半轴分别正比于 √λ₂ 与 √λ₃。

脊线： dx(s)/ds = e₁(x) (RK4；符号消歧：每步检查 e₁·e₁_prev > 0，否则取 −e₁) 管截面： a(s) ∝ √λ₂(x) , b(s) ∝ √λ₃(x) 着色 ： λ₁ / σ_vm / FA 给管上色 ⇒ 一次表达「走向 + 5 个自由度」 扩展：也可沿 e₂、e₃ 各做一族管，或把三族正交嵌套管并置，用以同时显示三个主方向与三个主值

优势是信息密度极高，且天然回避 glyph 的遮挡问题。劣势：

  • 主方向退化的奇点：λ₁ = λ₂（各向同性点）处 e₁ 未定义，积分会回转抖动。需要 degenerate point 检测并在其邻域跳过或转向。
  • 种子策略敏感：不同种子 → 完全不同的图。必须配种子优化（均匀 / 基于重要性采样）。
  • 时间一致性：非稳态场逐帧重积分会产生 pop-in/out。做法是在四维时空中做 space-time 流线，或做特征跟踪。

(3) 特征法：拓扑与不变量

  • 张量场拓扑：找出退化点（λ₁ = λ₂ 的点），分为 wedge / trisector 等类型，连同其分离曲面构成骨架。
  • 不变标量：直接对 σ_vm、p、I₁、c_l、c_p 画云图 —— 用户实际上绝大多数时候只需要这个。
  • 张量 LIC：把 LIC 的积分核换成主方向场，即可产生逐像素密度、无走样的各向异性图像。
领域共识 至今没有公认"最好的"张量可视化。Glyph 定量性好但全局结构差；超流线全局性好但参数敏感；不变量云图最实用但丢信息。实践中几乎总是 "不变量伪彩做主体 + 稀疏 glyph 做校验 + 局部超流线做解剖" 的三层组合。

2.5 体渲染（Direct Volume Rendering, DVR）

渲染方程

通常采用发射–吸收模型（低反照率近似，忽略散射）。沿视线参数 s：

dI(s)/ds = −τ(s)·I(s) + q(s) τ = 吸收系数，q = 源项，均由传递函数给出 离散 front-to-back 合成（逐采样点累积）： C_out ← C_out + (1 − α_out) · α_i · C_i α_out ← α_out + (1 − α_out) · α_i 提前终止： α_out > 0.99 ⇒ break（Early Ray Termination）

关键技术点

技术解决什么问题
预积分传递函数按点采样会让 α(d) 的非线性被欠采样，产生同心条带。对每对相邻采样值 (d_f, d_b) 预先计算积分结果，做成 2D LUT 查表。
梯度模辅助 TF用二维 TF (d, |∇d|)：只在 |∇d| 大处（材料界面、激波、边界层）给不透明度。这是把等值面的"边界感"注入体渲染的关键手法。
空空间跳过用 min/max 金字塔或八叉树剔除 α ≈ 0 的区块。
多通道融合同时把 p（伪彩）与 σ_vm（高光、高 α）送入两条 TF，得到"背景是压力、前景是屈服区"的复合视图。
等值面 + DVR 混合在 α(d) 上做一个尖峰，等价于产生一层"柔化的等值面"，兼具二者的解读性。
非结构网格 DVRFEM 通常是不规则四面体网格，需 cell projection、GPU 光线追踪 + BVH，或先重采样到规则网格。这是工程落地的主要成本项。
适用判断 体渲染是唯一能同时给出"整体分布 + 全部内部细节 + 无外遮挡"的方法，适合无法用切面表达的复杂三维结构（冲击波、多点接触、多孔介质、多连通屈服区）。代价是传递函数难调、计算成本高、定量性弱。因此它通常作为探索视图，最终结论仍回到切片云图 + 探针。

2.6 变形网格可视化（Deformed Mesh Visualization）

这一族把几何本身当作可视化媒介 —— 也是工业界最古老的应力可视化形式。

手段做法要点
变形位形 + 缩放因子 把参考网格顶点 X 推移到 x = X + s·u，s 通常为 1 / 5 / 10 / auto 必须在图例中显式写出缩放倍数。线性小变形分析中 s 常常是 10³ 量级；不标注会严重误导读者。
参考 vs 当前双视图 半透明参考轮廓 + 实体变形体；或并排左右对照 大变形超弹体必须明确当前画的是哪种构形，并据此选择 Cauchy / PK2 着色（见 §1.6）。
位移 / 应力着色 在变形后网格上刷 |u| 或 σ_vm u 与应力不在同一位置取得同一精度：有限元中 u 在节点 C⁰ 连续，应力常需磨平。
主拉伸线图理 在变形后表面做 LIC 或超流线，沿 e₁(C) 方向卷积 这是图形学贡献最独特的一支：把 DTI 的纤维束追踪思路搬到力学拉伸场，能直观看到"力流路径"。
裂纹与损伤场 相场 d ∈ [0,1]；或 XFEM 的 level-set 裂纹几何 建议用二值 + 实体（d > 0.9 才显示），避免"半透明紫色雾"这种糟糕做法。
接触压力 在接触 patch 上画 |t| 伪彩 + traction 矢量 是发现穿透 / 虚假分离最直接的方式。
振型动画 模态叠加 u = Σ φᵢ qᵢ sin(ωᵢ t) 必须标注这是归一化振型而非真实位移。
经验规则 位移很小时 → 放大 + 云图；位移很大时（软体）→ 真实位形 + 主拉伸线理 + 应变能云图；几何本身是面状的（布料、薄膜、壳）→ 膜内应力张量是 2×2，应使用双向主应力十字而不是三维椭球。

04在计算机图形学中的代表性应用

VFX / CG

特效工业：把科学场当作艺术控制柄

Houdini FLIP / POP / Vellum 的核心工作流就是持续看场：压力、速度散度、涡量约束、约束违背量。二次运动（secondary motion）、RBD glue 约束强度图、Voronoi 碎裂的种子分布，底层全是应力/应变可视化。压力–泊松迭代残差视图是判断解算是否收敛的标准手段。

REAL-TIME

实时图形：GPU 端即时反馈

游戏中往往需要逐帧可用的应力显示：布料 / 头发的 strain 着色驱动 LOD，可破坏物体的损伤累积图直接写入 albedo / emissive。技术路径通常是 compute shader → 2D/3D texture → 材质采样，牺牲定量性换取亚毫秒开销。

CAE / CAX

工程仿真后处理

ParaView / VisIt / EnSight / Tecplot 是上述六大方法族的事实标准实现。工业流程强调可复现的视图模板（同一色标、同一视角、同一相机），因为这些图本身就是审批签字的证据。

IN-SITU / EXASCALE

原位可视化

当单帧数据以 TB 计，存盘再读已不可行。ParaView Catalyst、VisIt Libsim、Ascent 把可视化管线直接嵌进求解器进程，在仿真推进的同时输出渲染图与统计量。这是超算时代的必然形态。

MEDICAL

医学可视化：血液动力学

WSS（壁面剪切应力）、OSI、FFR 三件套已是临床科研的标准输出，可视化对象是流固耦合的壁面场。DTI 中的扩散张量场与这里的应力张量共享几乎全部 glyph / LIC / 纤维束追踪算法。

HAPTICS / VR

交互仿真与沉浸式分析

SOFA、CHAI3D 等框架把应力场直接接到力反馈设备与 VR 头显：手不仅能"看见"还能"摸到"接触压力场。沉浸环境下深度感知问题的消失，是体渲染与张量 glyph 受益最大的场景。

图形学 vs 传统 SciVis 的差异

维度传统科学可视化计算机图形学取向
首要目标忠实、可定量、可复现可读性 + 视觉说服力 + 实时性
着色平坦、无阴影，避免干扰数值判读PBR、环境光、次表面散射，追求照片级真实
时间预算离线，允许分钟级16 ms / 帧，或严格受预算约束

典型产出论文图、工程报告交互工具、影视镜头、游戏资产

近年两者的边界正在模糊：一方面实时光线追踪、体路径追踪等影视技术进入科学工具；另一方面把 PBR 引入科学视图会污染定量判读（高光会被误读为高值），因此业界共识是"分析视图用平坦着色，展示视图用电影级渲染，两者分离"。

05技术挑战

C1 · DYNAMIC RANGE

动态范围与量纲

从生物软组织的 kPa 到冲击波的 GPa，跨越 9 个数量级。任何时候都不能假设线性映射可用。更隐蔽的问题是符号约定：固体力学拉正压负、岩土压正拉负、CFD 中的压力常是相对值。三套约定在同一项目里混用是灾难的常见来源。

C2 · SCALE

数据规模与 I/O

十亿单元、数千时间步 = PB 级。传统"落盘—后处理"模式已失效，必须走向 in-situ、有损 / 无损压缩（SZ、ZFP、TTHRESH）、以及图像化的 Cinema 数据库（存渲染结果而非原始数据）。

C3 · OCCLUSION

深度感知与遮挡

三维场投影到二维屏幕必然损失信息。伪彩色不携带深度，"红色高应力区在前面还是后面"单看颜色无法判断。缓解手段：透视 + SSAO + 雾 + 剖切 + 立体渲染；glyph 的密度–遮挡权衡至今没有通用解。

C4 · PERCEPTION

感知与色标

彩虹色标的非单调亮度会制造虚假脊线；红绿色盲友好性在跨团队评审中是硬约束；跨图对比时的色标锚定不一致会造成系统性误判。结论：默认 viridis / cividis，有符号量用发散型，把 jet 留给"大家都这么看"的历史图。

C5 · TENSOR AMBIGUITY

张量表达的不完备性

核心开放问题。6 个自由度无法无损映射到二维画面；glyph 尺寸、形状、颜色三个通道会彼此干扰。没有一种张量可视化通过过严格的定量可用性 user study 全面胜出。此外张量场不能简单线性插值（欧氏插值会导致 swelling effect：插值后 FA 反而增大），必须使用 Log-Euclidean 或 Riemannian 度量下的插值。

C6 · TEMPORAL

时间一致性

非稳态场的流线 / 超流线 / 粒子每帧重算会产生抖动、pop-in、种子漂移。解决方向是四维时空流线（path-surface）与特征跟踪（对极值点做帧间匹配），但计算成本高。

C7 · ARTEFACT

数值伪影 vs 真实现象

这是最危险的一类：可视化会忠实显示错误。checkerboard 压力、沙漏模式、剪切自锁（看起来异常刚硬）、菱形单元的方向偏置、SPH 粒子噪声、node-wise 磨平抹掉峰值 —— 都需要靠经验识别，而非工具自动标注。

C8 · UQ / ENSEMBLE

不确定性与集合可视化

当输入参数不确定（材料参数、边界条件），输出是场的概率分布而不再是一个场。如何在一张图里表达"均值 + 方差 + 空间相关"是开放问题；均值云图 + 置信区间切片是目前的可行折衷。

最该记住的一条 可视化天生是降维的有损过程。任何一张应力图都是某个投影下的观察结果，而不是客观事实本身。负责任的呈现至少要包含：色标及其归一化方式、单位、变形缩放倍数、应力度量类型（Cauchy / PK）、构形（参考 / 当前）、网格分辨率。缺任何一项都可能让读者得出相反结论。

06发展趋势

  1. 原位可视化成为默认形态（In-situ & In-transit）。Catalyst / Ascent / Cinema 的路线是"少存数据、多存图像与提取量"。配套的是 参数化图像数据库 —— 事后在图像空间里漫游，而非重新计算。
  2. 神经压缩与隐式神经表示。用小型 MLP / 网格 + hash encoding 压缩 TB 级标量场到 MB 级，查询时重建。这既解决了存储，也让分辨率无关的采样成为可能，代价是引入了需要可视化本身的重建误差场。
  3. 可微可视化。把渲染器当作 loss 的一部分：已知目标图像反求材料参数、同化观测数据、自动优化传递函数 —— 可视化从"单向输出"变成"闭环参与"。
  4. 拓扑数据分析落地。Morse–Smale complex、contour tree、persistence diagram 从论文走向 tool default：自动提取涡核、分离面、屈服区的拓扑骨架，把"人工挑阈值"变成"按持久性排序"。
  5. 自动视图推荐。用学习模型预测信息熵最大 / 遮挡最小的视点与切面，或自动生成"最有信息量的一组小图"。这是把可视化从手工技艺变成可自动化流程的关键一步。
  6. 不确定性与集合可视化的标准化。随着 UQ 仿真与代理模型普及，"带误差棒的场"会逐步标准化为均值 + 方差双通道 + 概率等值面（spaghetti plot / contour boxplot）。
  7. 沉浸式分析 XR。VR 天然解决深度歧义，对体渲染与三维 glyph 的收益最大；瓶颈在于交互帧率与长时间使用的舒适度。
  8. 浏览器化与 WebGPU。以往必须装 ParaView 的视图，现在可以在浏览器里跑。这为协作评审、教学、以及把仿真结果嵌入产品页面打开了通路。
  9. 影视级渲染与科学准确性的统一。体路径追踪（volumetric path tracing）开始在 GPU 上实时化；下一阶段的方向是"同一份数据，两套渲染管线，共享同一个传递函数"。
  10. 面向 AI 代理的自然语言查询接口。"帮我找出所有超过许用应力 1.5 倍的区域并出对比图" —— 这类请求正在从脚本走向意图理解。

07实践检查清单

7.1 出图前必检的 10 项

  1. 色标类型是否与数据语义匹配（顺序 / 发散 / 是否取对数）？
  2. 归一化是全局的还是逐帧的？多图对比时是否一致？
  3. 单位写了吗？符号约定（拉正还是压正）标注了吗？
  4. 应力度量是 Cauchy 还是 PK？渲染构形与之匹配吗？
  5. 变形缩放倍数写了吗？
  6. 云图上的应力是否经过磨平？是否可能掩盖了峰值？
  7. 极值点验证过吗（至少和积分点 / 探测值比对一次）？
  8. 做了网格收敛性检查吗（至少 2–3 档密度）？
  9. 颜色是否是色盲友好 + 灰度打印可读？
  10. 图上看起来的"结构"，用另一个方法（如切片 vs 等值面 vs 体渲染）交叉验证过吗？
